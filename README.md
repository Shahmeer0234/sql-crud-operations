# SQL CRUD Operations & Database Fundamentals 🚀

Welcome to the **SQL CRUD Operations & Database Fundamentals** repository! This repository contains hands-on SQL practice projects covering database creation, table design, CRUD operations, relational databases, filtering, sorting, and SQL queries using a Relational Database Management System (RDBMS).

---

## 📁 Repository Structure & Overview

| File Name | Database Name | Key Concepts Covered |
| :--- | :--- | :--- |
| **practice.sql** | `practice_db` | CREATE DATABASE, CREATE TABLE, INSERT, UPDATE, TRUNCATE, DROP |
| **school.sql** | `school_db` | Teachers table, Data insertion, Updates, Database cleanup |
| **school_management.sql** | `school_management` | Students & Courses tables, WHERE clause, ORDER BY |
| **company.sql** | `company_db` | NOT NULL, DEFAULT, ALTER TABLE, DELETE |
| **bank_management.sql** | `bank_db` | Customers, Accounts, Transactions, PRIMARY KEY, FOREIGN KEY, JOIN, WHERE, ORDER BY |

# 💻 How to Run These Scripts

### Clone the repository

```bash
git clone https://github.com/Shahmeer0234/sql-crud-operations.git
```

### Navigate into the project

```bash
cd sql-crud-operations
```

### Open any SQL file in your preferred SQL environment

Examples:

- MySQL Workbench
- phpMyAdmin
- MariaDB
- XAMPP
- VS Code + SQL Extension

Execute the script to create the database, tables, and practice SQL queries.
